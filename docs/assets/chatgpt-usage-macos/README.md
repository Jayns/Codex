## 复用 Windows 版的截图

### 与平台无关（网页，无需重拍）

`../chatgpt-usage/` 下的 `步骤1/2/3-*` 和 `步骤11-查看使用记录` —— 都是服务商
网站，浏览器外框虽是 Windows 但网页内容跨平台一致。

### ChatGPT 桌面应用界面（目前仍是 Windows 外观，建议在 Mac 上重拍）

这些图右上角是 Windows 的最小化/最大化/关闭按钮，`步骤8/10` 还带 Windows
的窗口内菜单栏（macOS 上应在系统菜单栏、窗口用红黄绿灯）：

| 复用的文件 | macOS 版步骤 | 建议重拍为 |
| --- | --- | --- |

| `步骤8-切换模式.png` | 12. 切换工作模式 | mac 上左上角 Codex 下拉菜单 |
