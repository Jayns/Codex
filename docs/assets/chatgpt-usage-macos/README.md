## 已停用（公证后不再走这条流程，仅供“常见问题”排障参考）

自便携版接入 Developer ID 签名 + Apple 公证后，正常发布的 `ChatGPT Launcher`
双击即可直接打开，不再需要下面这三步的手动放行流程，正文已移除对应步骤和截图
引用。以下文件保留在仓库里，只在极少数场景（拿到的是未公证的旧拷贝、或传输
中签名被破坏）需要在“常见问题”里给用户说明时使用：

| 文件 | 曾对应的步骤 | 内容 |
| --- | --- | --- |
| `未打开程序.png` | 首次打开被拦截：先点“完成” | “未打开 …… Apple 无法验证”弹窗（按钮：完成 / 移到废纸篓） |
| `仍要打开.png` | 在“系统设置”中放行 | 系统设置 → 隐私与安全性，“已阻止 …… 以保护 Mac” + “仍要打开” |
