# macOS 使用说明 — 待补截图

以下截图供 [`../../ChatGPT便携版使用说明-macOS.md`](../../ChatGPT便携版使用说明-macOS.md) 引用，
需要在 Mac 上补拍后放入本目录（文件名保持一致）。

| 文件名 | 对应步骤 | 截图内容 |
| --- | --- | --- |
| `步骤4-安装ChatGPT.png` | 4. 安装官方 ChatGPT 应用 | 打开 `ChatGPT.dmg`，把 ChatGPT 图标拖入「应用程序」文件夹的窗口 |
| `步骤5-便携包内容.png` | 5. 查看便携包内容 | Finder 里显示解压后的文件夹：`ChatGPT Launcher.app`、`Codex 皮肤管理工具.app`、`使用说明.txt` |
| `步骤6-安全提示.png` | 6. 首次打开安全提示 | 双击 App 后弹出「Apple 无法验证……是否包含恶意软件」，按钮为「完成 / 移到废纸篓」 |
| `步骤7-隐私与安全性.png` | 7. 在系统设置中允许 | 系统设置 → 隐私与安全性，底部「已阻止使用 "ChatGPT Launcher"…」+「仍要打开」按钮 |
| `步骤8-配置窗口.png` | 8. 填写连接信息 | macOS 版配置窗口（Cocoa 外观），5 个字段 + 「浏览」+「退出 / 保存并启动 ChatGPT」；可加红色标注 |
| `步骤10-拖入Dock.png` | 10. 放入 Dock | 把 `ChatGPT Launcher.app` 拖进「应用程序」或 Dock 的动作 |
| `步骤13-皮肤管理.png` | 13. 更换皮肤 | `Codex 皮肤管理工具.app` 的皮肤管理界面 |

## 可选补拍（否则复用 Windows 版图）

- 首次运行时 macOS 的权限授权提示（若有）
